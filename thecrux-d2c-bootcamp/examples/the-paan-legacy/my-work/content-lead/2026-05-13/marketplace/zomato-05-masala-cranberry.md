## Description (~170 words)
The Masala Cranberry is our modern paan. Cranberry, hand-roasted Indian masala (fennel, cardamom, clove, a touch of black pepper), almond slivers, on the meetha base.

Cranberry is not a paan ingredient anyone's grandmother used. We added it because it does what gulkand does (the slightly tart-sweet finish that paan needs to be a digestive) but with a more modern edge. Some customers love it. A few find it strange the first time and order it twice. We are okay with both.

Box of 6, ₹289. Tobacco-free, supari-free, eat-and-swallow. Hand-roasted, small batch, named ingredients.

FSSAI License #{number}. Suitable from age 6+ (some adults find the black-pepper kick mild; for kids, start with a half-paan).

Allergen note: contains tree nuts (almond). Made on a production line shared with cashew SKUs; cross-contact with cashew possible.

The SKU we recommend if you want to send a paan box to a friend who thinks they already know what paan tastes like.
