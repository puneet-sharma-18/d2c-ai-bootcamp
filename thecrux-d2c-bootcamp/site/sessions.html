Appendix · Take-home upgrades

Optional · post-workshop

Two add-ons you can layer on the same dashboard. Restyle it with a different design system. Add a chatbot that answers questions about your data with inline charts. Run in either order or both. See the appendix for the full prompts.

Upgrade A

Restyle the dashboard

Swap design.md for a different system. The dashboard rebuilds against the new tokens. Data is untouched.

Inputs
design.md (root) existing dashboard.html getdesign.md catalog
Steps
1Pick a system.Genesis, Cohere, Linear, Stripe or bring your own.
2Download and replace.npx getdesign@latest add cohere then copy its DESIGN.md over ./design.md.
3Delete the old dashboard.rm my-work/growth-analyst/dashboard.html. Skill rebuilds only when the file is gone.
4Rerun /growth-analyst.Reads the new design.md in full. Rebuilds dashboard.html.
5Verify.Serve via python3 -m http.server 8000. Same data, new visual language.
Outputs
design.md replaced dashboard.html re-painted
Upgrade B

Add a chatbot

A chat panel on the dashboard that answers natural-language questions. Proxies to OpenRouter with numbers.json plus the brief plus raw CSVs as context. Renders charts inline.

Inputs
OpenRouter API key python3 + requests + dotenv numbers.json + brief + CSVs
Steps
1Ask Claude to add the chatbox.Generates server.py with /api/chat proxy, .env scaffold and a chat panel styled to design.md.
2Add your API key.Paste into .env. Workshop key from instructor or your own at openrouter.ai/keys.
3Start the server.python3 server.py. Confirms model and API key on boot.
4Open and ask.Click the ? bubble. Four starter prompts plus your own. History preserved for follow-ups.
Outputs
server.py .env (gitignored) dashboard.html with chat panel
