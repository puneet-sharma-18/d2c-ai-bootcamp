01 · The arc

Two days. Nine primitives. Ten teammates.

Day 1 installs four primitives. Each one unlocks a teammate. Day 2 braids five advanced concepts into the existing primitives and finishes with the Captain.

Day 1 Saturday · Intelligence + content

Profile, playbooks, plugs, parallel teammate. By Sunday morning you can answer four questions cleanly: What is CLAUDE.md? What is a skill? What is an MCP? What is a subagent?

05 · Glossary

Plain words for the nine moving parts.

If a teammate mentions one of these and you blank for a second, this is the page to scan.

Primitive · Day 1

CLAUDE.md

A markdown file at the root of your repo. It holds your brand profile: voice rules, products, customers, compliance lines, banned words. Claude reads it on every session. Every teammate respects it.

Lives at CLAUDE.md
Primitive · Day 1

Skill

A folder with a SKILL.md inside. Claude autoloads it when the trigger phrase or task fits. Think of it as a job description plus a checklist a teammate runs every time they work.

Lives at .claude/skills/<name>/SKILL.md
Primitive · Day 1

Slash command

A short text command you type to trigger an action (for example /interview-me). Defined as a single markdown file. The Brand Brain uses one to interview you and fill CLAUDE.md.

Lives at .claude/commands/<name>.md
Primitive · Day 1

MCP

Model Context Protocol. The plug that lets a teammate read live data from Shopify, Google Drive, Gmail and others. Wired in Session 3. Once live, the same skill reads from real systems instead of pasted files.

See Resources for the full Tier 1 to Tier 4 MCP list
Primitive · Day 1

Subagent

A specialised teammate that runs in its own context window for bigger jobs. The Content Lead and Performance Marketer are subagents because they produce 30+ outputs in one run. The Captain is one too.

Lives at .claude/agents/<name>.md
Concept · Day 2

Parallel dispatch

Your main session (the orchestrator) spawns several subagents in parallel. Used by Performance Marketer to produce 50+ ad variations across 5 angles in a single run instead of running them one by one.

See Session 6
Concept · Day 2

MCP-fed iteration

A loop where a skill reads live data via an MCP, diagnoses what is off, rewrites, and pushes the new version back as a draft. Storefront Specialist uses this on Shopify PDPs.

See Session 7
Concept · Day 2

Hooks + triggers

When event X happens, run action Y. An RTO spike triggers the Ops Manager to draft a vendor escalation. A new review triggers Voice of Customer to refresh themes.

See Session 8
Concept · Day 2

Scheduled wake-up

A time-based hook. Every Monday at 09:00 IST the Growth Analyst runs the weekly brief and drops it in my-work/growth-analyst/. You wake up to the file.

See Session 9
Concept · Day 2

Captain pattern

One subagent reads the index file from every teammate (not the raw outputs) and produces a cross-cutting recommendation plus the 90-day roadmap. Token-cheap because indexes are ~500 tokens each.

See Session 10
Convention

Index file

Every Day 2 teammate produces a short index of their work (~500 tokens) on top of the raw output. The Captain only reads indexes. This is what keeps the 90-day roadmap affordable on Pro plan.

Lives at my-work/<teammate>/INDEX.md
Convention

Default vs Power scope

Every skill asks the founder to pick scope at the start. DEFAULT fits the workshop slot on Pro plan. POWER is for Max plan or take-home work and produces a wider deliverable.

Picked at the start of every skill or subagent run
